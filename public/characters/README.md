# 放你自己的角色图片

把图片放进这个目录，文件名用下面三个之一，网站会自动替换掉内置的自绘 Q 版形象：

| 文件名 | 对应角色 | 建议尺寸 |
|--------|----------|----------|
| `hoshino.png` | 小鸟游星野（首页主形象 + 专注页） | 宽高比约 4:5，≥ 400×500 |
| `arona.png` | 阿洛娜（挂件） | 同上 |
| `plana.png` | 普拉娜（挂件） | 同上 |

说明：

- 建议用 **背景透明的 PNG**，效果最好；网页里会自动加一层投影和漂浮动画。
- 只需要放你想换的那一个，没放的角色继续用内置自绘形象。
- 换图后要重新构建（`npm run build`）才会生效。
- 图片会随网站一起发布。请确认你有权使用该图片；本站为个人非商业用途，
  但公开仓库里的图片仍建议使用你自己绘制或已获授权的素材。
